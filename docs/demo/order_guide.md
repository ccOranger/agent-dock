# 订单与物流自助指南

> 演示用示例文档：订单查询、物流追踪、订单修改与退换入口。

## 一、查询订单

1. 提供订单号（形如 SO-2026xxxx）或下单手机号。
2. 支持按订单状态筛选：待付款、待发货、运输中、已完成、已取消。
3. 未登录客户可凭手机号 + 验证码查询近 90 天订单。

## 二、物流追踪

- 订单发货后可在“订单详情 - 物流信息”查看承运商与运单号。
- 物流信息一般每 2-4 小时更新一次，偏远地区可能延迟。
- 显示“已签收”但未收到货：先联系快递员核实，24 小时内未解决可提交工单。

## 三、修改订单

- **待付款**：可直接取消后重新下单。
- **待发货**：支持修改收货地址与备注，需与客服确认后操作。
- **运输中 / 已完成**：无法修改地址，可联系承运商协商改派。

## 四、取消与退换

- 待付款、待发货订单可直接取消，款项按原支付渠道退回。
- 签收后 7 天内可申请退货或换货，需保持商品及包装完好。
- 退换申请入口：“订单详情 - 申请售后”，提交后 1 个工作日内审核。

## 五、常见问题

- **多久发货**：现货订单 48 小时内发出，预售商品以商品页说明为准。
- **可以开发票吗**：支持电子普通发票，订单完成后申请。
- **运费谁承担**：质量问题由商家承担；无理由退货由客户承担往返运费。
