## 许可变更（破坏性，请先读）

本版将项目许可由 Apache-2.0 改为 **CC BY-NC-SA 4.0**（署名—非商业性使用—相同方式共享）：

- **仅限非商业使用**：不得对外销售、按订阅或授权收费，也不得作为收费产品或收费服务的一部分交付。
- **相同方式共享**：修改后对外发行须继续采用同一许可。
- **署名**：需保留原作者署名与许可声明。
- 商业使用需另行取得书面授权，见 [LICENSE](../../LICENSE)。

原因：核心框架 `hello-agents 0.2.9` 本身以 CC BY-NC-SA 4.0 分发，宽松许可无法与之共存。将自有代码统一为同一协议，
是为了消除"自有代码比依赖更宽松"的分发冲突，而不是新增限制。详见 [NOTICE](../../NOTICE)。

为什么这不构成"回收已授权"：仓库自创建起一直是私有，Apache-2.0 从未对外生效，`v0.2.0` tag 也从未公开。
从本版起，所有使用者一律按新许可。

## 本版内容

### 后台样式基座（`admin-frontend`）

- 新增设计令牌 [`styles/theme.css`](../../admin-frontend/src/styles/theme.css)（`--cs-*` 令牌 + 覆盖 Element Plus 变量）
  与三个基座件：[`PageHeader`](../../admin-frontend/src/components/PageHeader.vue)（页头与操作区）、
  [`FilterBar`](../../admin-frontend/src/components/FilterBar.vue)（筛选栏）、
  [`usePagedList`](../../admin-frontend/src/composables/usePagedList.ts)（分页、加载、空态复用）。
- 16 个页面与 `AdminLayout` 迁到基座，去掉页面内重复的卡片头、筛选栏、分页样板与硬编码色值；
  `MemoryView` / `InquiriesView` 随下面的记忆查询改动一并跟进。
- 语言包切到 `zh-cn` 基线：分页文案统一为「总数 N」「N/页」，表格空态、确认框按钮、日期面板随之中文化。

### 记忆查询增强

- `/memory/users/{id}` 支持两种主体标识：裸 UUID 按 `user_id` 查，`visitor:<uuid>` 按 `visitor_id` 查。
- 非法客户 ID 由 500 改为 400，不再把参数错误报成服务端异常。
- 后台记忆页支持关键词本地过滤、长内容折叠与一键复制；咨询列表新增「记忆」直达入口。
- 新增 8 个接口用例（[`tests/test_memory_api.py`](../../backend/tests/test_memory_api.py)）。

## 升级

- **数据库**：本版无表结构变更，不需要执行 `python -m app.migrate`。
- **后端**：仅记忆查询与后台接口有改动，重启即可。
- **前端**：样式基座是构建期产物，需要重新构建镜像或执行 `npm run build`。
- 若从 v0.2.0 之前的版本升级，仍需先跑迁移（schema 8 → 10），见 [部署指南](../deployment.md)。

## 已知限制

- **非商业**：本版起项目整体仅限非商业使用（见上节），商业部署需先取得上游与本项目授权。
- **单租户**：仅预留 `tenant_id`，不做租户隔离；SSO、计费、用量账单不在本版范围。
- **依赖告警**：`npm audit --omit=dev` 为 0 告警；全量 6 项均在 devDependencies（`vitest` / `vite` 升级链），
  见 [安全策略](../../SECURITY.md)。
- **评测不进 CI**：`scripts/eval.py` 打真实模型，发布前手动带 `--baseline latest` 跑一次。
