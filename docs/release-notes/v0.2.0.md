# AgentDock v0.2.0

> 首个对外版本：多场景智能客服基座（单租户、可私有化部署）。
> 本文可直接作为 GitHub Release 正文；完整变更见 [CHANGELOG](../../CHANGELOG.md)。

## 这是什么

AgentDock 是一个能自己跑起来的对话机器人基座：意图路由 + 工具调用 + RAG + 三层记忆 + 人工接管，
管理台里配场景、知识库、Agent、固定话术与权限，对外提供 HTTP / SSE 与可嵌入的网页挂件。
面向"想自己部署、自己改业务"的技术团队，不提供 SaaS 托管。

## 本版内容

- **多场景**：默认客服场景 + IT Helpdesk 场景，场景级隔离（知识库、Agent、固定话术、追踪、用量）。
- **人工接管**：`active → handover → human_handling → active|closed` 四态，抢单、越权校验、坐席话不入机器人上下文。
- **RBAC**：16 个菜单模块 × 读/写两级权限，人员-角色-菜单矩阵；admin 旁路、未知 key 白名单丢弃。
- **数据分析**：全量三率（转人工 / 解决 / 错误）+ 链路三率（工具成功 / 兜底 / RAG 命中），后者标注采样口径。
- **链路追踪**：一轮对话一行（拍平列 + `spans` JSONB），十种 span，失败轮次全量保留。
- **版本化迁移**：`scripts/migrations/NNNN_*.sql` + `schema_migrations`，`python -m app.migrate`（`--check` / `--dry-run` / `--backup`）。
- **移除**：「用量报表」并入数据分析；「授权与版本」（License 与版本分层）整体下线，不再区分社区版/企业版。

## 快速开始

```bash
git clone <repo-url> && cd smart-cs
cp backend/.env.example .env      # 填模型与 Embedding 的 Key
docker compose up -d
# 管理台 http://localhost:8080/admin/   聊天页 http://localhost:8080/
```

演示账号由 `SEED_DEMO=true` 决定，默认关闭；`README` 与 [快速开始](../quickstart.md) 有完整步骤与常见报错。

## 镜像构建

`docker/backend.Dockerfile`（Python 3.12-slim，非 root）/ `docker/web.Dockerfile`（多阶段构建，Nginx 托管
管理端 + 聊天端并反代 `/api`）。CI 的 `docker` job 只构建不推送，用来在 PR 阶段暴露依赖与产物问题。

## 升级

存量库执行 `python -m app.migrate`（schema 8 → 10）。升级前建议 `--backup`；
没有表结构变更的部署不受影响。详见 [部署指南](../deployment.md)。
