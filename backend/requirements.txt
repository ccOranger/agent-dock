# ============ HelloAgents 框架（核心） ============
# 使用 [memory,protocols] 扩展：
#   - memory    → 四层记忆（episodic 依赖 Qdrant 向量库、semantic 依赖 neo4j/spacy 等）
#   - protocols → MCPTool / 协议适配（a2a-sdk）
# 之所以此前冲突：fastapi/httpx 被 "==" 钉死，而 protocols 拉取的 a2a-sdk 要求更高版本；
# 下方改为宽松下限(>=)后，解析器可自动上探到兼容版本，冲突消除。
