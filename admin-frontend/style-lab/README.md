# 风格对比实验（Style Lab）

> 已落地：管理后台选定 **企业蓝**，令牌已写入 `admin-frontend/src/styles/theme.css`。
> 本目录保留作为后续换肤/备选方案的对照样本。

同一屏后台界面（侧栏 + 顶栏 + 统计卡 + 筛选 + 表格 + 会话详情），用五套设计令牌渲染。
目的是先「用眼睛比」，再决定改哪里，避免直接动 `theme.css` 之后来回返工。

## 打开方式

双击 `index.html` 即可，无需构建、无外部依赖、离线可用。

- 右下角浮条切换风格：`粘土外壳` / `企业蓝` / `Material You` / `极简` / `新粗野`
- 也支持 `index.html?theme=clay|enterprise|m3|minimal|brutal`，方便开多个标签页并排看
- `compare.html` 是五套风格的等比例缩略并排，用来先看整体气质
- 勾选「表格也捏成粘土（反例）」可看到**把数据面也软化**的代价：行距变大、扫描速度下降、状态色块失去支撑

## 五套风格在验证什么

| | 粘土外壳 | 企业蓝 | Material You | 极简 | 新粗野 |
|---|---|---|---|---|---|
| 定位 | 辨识度优先，只覆盖「可捏的东西」 | 客户预期优先，稳 | 系统感优先，色阶驱动 | 完成度优先，不改观感 | 记忆点优先，克制用色 |
| 表面 | 暖米底 + 柔光阴影 + 大圆角 | 白底 + 细边框 + 弱阴影 | 淡紫表面 + 金色阶分层，无硬边 | 近白底 + 发丝边框 | 2px 硬边 + 错位实心阴影 |
| 数据面 | 表格扁平、细线分隔 | 斑马行 | 去边框、留白更大 | 扁平、行高更紧 | 边框加重、行分隔更强 |
| 侧栏 | 浅暖色 | 深海军蓝 `#001529` | 淡紫 + 主色 pill 选中态 | 近黑 | 纯黑 + 黄色选中块 |
| 主色 | 陶土红 `#b25a35` | 蓝 `#1677ff` | 蓝紫 `#2f5da8` | 蓝 `#2563eb` | 硬黄 `#ffd43b` + 黑字 |
| 圆角 | 卡片 18 / 控件 13 | 卡片 8 / 控件 6 | 卡片 20 / 按钮药丸 | 卡片 10 / 控件 8 | 4 / 4 |
| 渲染成本 | 中（多层阴影） | 低 | 低-中 | 最低 | 最低 |
| 改造量 | 中 | 最低 | 中高（组件形态差异大） | 最低 | 低 |

## 观察点（按重要性）

1. **表格还能不能扫**：找「转人工」那行需要多久；软阴影、斑马行、去边框各自对扫描速度的影响。
2. **状态标签是否还立得住**：`进行中 / 转人工 / 已关闭` 三色在小面积上是否可分辨；Material You 的浅色容器是否让标签「飘」在背景上。
3. **按钮层次**：主按钮（导出 CSV / 查询 / 发送）和次按钮是否一眼可分；粘土的浮起、企业蓝的薄高光、M3 的药丸，三者观感差异最大。
4. **输入框边界**：粘土靠内阴影、M3 靠填充色、企业蓝靠描边——哪种在长时间使用中最不容易被误读成禁用态。
5. **8 小时疲劳**：暖米底会不会发闷、M3 的淡紫会不会发飘、企业蓝会不会「像每天都见、但不出错」。

## 落地时绕不开的三件事

1. **Element Plus 覆盖点**：`el-card / el-button / el-input / el-table / el-drawer / el-dialog / el-tag / el-pagination` 需要 `:deep()` 或全局覆盖。Material You 最深（按钮要药丸、输入要填充、卡片要去边框），企业蓝最浅（几乎只换色值）。
2. **21 处硬编码颜色**：`rgba(64,158,255,…)` 散在 `TakeoverView / PageHeader / AnalyticsView / RouterInfoView / IntegrationsView` 里，不收敛成 `--cs-brand-soft` 之类的变量，换肤就会露出原色。
3. **对比度**：暖底会压低辅助文字对比度；M3 的浅色标签容器要单独验一次文字对比；粘土主题下不要用纯白文字压浅色块。

## 建议的推进顺序

1. 先在 `compare.html` 里看气质，再用 `index.html` 逐套看细节，选定一套（或「粘土外壳 + 极简数据面」这类混合）。
2. 只改登录页做实物验证：`LoginView.vue` 单文件、无表格、不影响主流程。
3. 再按「侧栏 → 卡片/按钮 → 表格 → 表单」逐层替换，每层留回退开关（`[data-theme]`）。
